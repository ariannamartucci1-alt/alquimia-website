# Alquimia — Website v2

Vitrina web de Alquimia. No es un e-commerce transaccional: los productos son prototipos y la conversión prevista es la lista de espera.

## Estructura
- Inicio: `index.html`
- Colección: `coleccion.html`
- Transformación: `transformacion.html`
- Nuestra historia: `nuestra-historia.html`
- Hero Bag: `producto-hero.html`
