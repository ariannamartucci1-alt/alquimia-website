# Alquimia — Website v1

Sitio vitrina navegable de Alquimia, construido a partir de la estrategia, UX, SEO y asset system definidos en el PFM.

## Estado
- Sitio estático responsive.
- Home, Collection, 2 Product Pages, Transformation, Our Story y Waitlist.
- Assets visuales extraídos de la versión vigente del PFM.
- La waitlist tiene actualmente una confirmación local de demostración. La conexión real con el sistema de datos + Make queda para la fase de automatización.

## Publicación
Puede publicarse gratuitamente con GitHub Pages. Subir el contenido de esta carpeta a un repositorio público y activar Settings → Pages → Deploy from branch → main / root.
